# 1. server configuration

server configuration page looks like bellow:

<img src="../../assets/images/server.png" width="30%" alt="servers configuration">

- ## add server
just tap right top **'+'** and fill the server address, port, username and password etc.
- ## edit server
tap the edit icon: <img src="../../assets/images/edit_server_logo.png" width=40 alt="edit server">
- ## delete server
tap the remove icon: <img src="../../assets/images/delete_server_logo.png" width=40 alt="delete server">


# 2. manage torrent

## normal torrent operations

By **long press** torrent, a popup menu will show like bellow:

<img src="../../assets/images/torrent_op.jpeg" width="30%" alt="torrent operations">

Here you can pause, delete, set label and category, move or rename the torrent etc.

## batch mode (premium only)

Tap the multi-selection icon <img src="../../assets/images/batch_logo.png" width=40 alt="batch icon"> will enter batch mode

<img src="../../assets/images/batch_mode.jpeg" width="30%" alt="torrent operations">

Here you can manage multiple torrents at once

## torrent details

Tap the torrent you interest, will show like bellow:

<img src="../../assets/images/torrent_detail.png" width="30%" alt="torrent operations">

## add new task

Tap the **'New'** button on the bottom menu bar, you will see:

<img src="../../assets/images/new_torrent.jpeg" width="30%" alt="add new torrent">

You can add new task from torrent file or from http or magnet link url.

tap **'More options ...'** to specify more torrent start options, such as category, label, up/download rate limits etc.

## stop all task

Tap **'Stop All'** will pause all the tasks.

## manage categories and labels

Tap **'Category&Lables'** will show below:

<img src="../../assets/images/category_and_label.jpeg" width="30%" alt="category label">

You can add, delete categories and labels.

## rss (premium only)

Tap **'rss'** will show below:

<img src="../../assets/images/rss.jpeg" width="30%" alt="rss">

You can add feeds and manage rss autodownload rules.
